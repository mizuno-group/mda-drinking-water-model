# Data

`raw/` contains source tables used by the analysis notebook. `processed/sample_metadata.csv` contains harmonized sample metadata, and `processed/fig2e_existing_patch_counts.csv` contains slide-level normal and abnormal patch counts used for Fig. 2E.

`manifest.csv` records byte size, SHA-256 digest, row count, and column count for included data files. Blank fields represent missing values.
